# C++ Calculator

A simple calculator built using C++ that performs basic arithmetic operations with basic error handling and an interactive console-based interface.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Basic error handling
- Interactive console interface

## Technologies Used
- C++

## How to Run

1. Clone or download this repository.
2. Open the project in a C++ IDE or terminal.
3. Compile the `calculator.cpp` file.
4. Run the generated executable.

## Learning Outcomes
- Practised C++ programming fundamentals.
- Applied arithmetic operators and conditional statements.
- Improved understanding of user input and output.
- Practised basic error handling.
